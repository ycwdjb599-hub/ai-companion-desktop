# 千问 Character：八步完成连接

[API Key](https://bailian.console.aliyun.com/cn-beijing/model/settings/api-key) · [Official guide](https://help.aliyun.com/zh/model-studio/get-api-key) · [Workspace ID](https://help.aliyun.com/zh/model-studio/obtain-the-app-id-and-workspace-id)

## 1. 打开百炼北京 API Key 页面并登录。

![Step 1](setup/qwen-guide/step-01-login.png)

## 2. 点击「创建 API Key」，使用默认业务空间即可。

![Step 2](setup/qwen-guide/step-02-create.png)

## 3. 填写描述，确保权限包含千问 Character，点击「确定」。

![Step 3](setup/qwen-guide/step-03-confirm.png)

## 4. 点击 API Key 旁的「复制」。

![Step 4](setup/qwen-guide/step-04-copy-key.png)

## 5. 回到 AI伴侣，将 Key 粘贴到 API Key 输入框。

![Step 5](setup/qwen-guide/step-05-paste-key.png)

## 6. 回到百炼，点击顶部业务空间，复制「业务空间 ID」。

![Step 6](setup/qwen-guide/step-06-copy-workspace.png)

## 7. 回到 AI伴侣，将空间 ID 粘贴到对应输入框。

![Step 7](setup/qwen-guide/step-07-paste-workspace.png)

## 8. 点击「检查并继续」，成功后继续准备资源并开始陪伴。

![Step 8](setup/qwen-guide/step-08-continue.png)


API usage is billed by your provider. Do not share your key or post it in screenshots. The default workspace is supported; use the actual ID from the same workspace as your key.
